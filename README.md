# File Organizer 🗂️

A Python script that automatically organizes files in a directory based on file extensions. It sorts your messy folders into neatly categorized folders like `Documents`, `Images`, `Audio`, `Video`, `Archives`, `Executables_Scripts`, and `Others`.

## 💡 Features
- Cross-platform terminal clearing
- File categorization based on extensions
- Automatic folder creation
- Clean console feedback after processing
- Easily customizable extension list

## 🛠️ How It Works
1. Run the script.
2. Input the path of the folder you want to organize.
3. Let the script sort files into categorized folders.

## 🗂️ Categories Covered
- **Documents**: `.txt`, `.pdf`, `.doc`, `.docx`, etc.
- **Images**: `.jpg`, `.png`, `.webp`, `.ico`, etc.
- **Audio**: `.mp3`, `.wav`, etc.
- **Video**: `.mp4`, `.mov`, etc.
- **Archives**: `.zip`, `.rar`, etc.
- **Executables_Scripts**: `.exe`, `.py`, `.js`, etc.
- **Others**: `.html`, `.css`, `.json`, etc.

## ✅ Example Output
```
Moved 'report.pdf' to 'Documents' folder.
Moved 'song.mp3' to 'Audio' folder.
```

## 🔧 Customization
Want to support more file types? Simply edit the `file_extensions` dictionary in the script to add your desired extensions.
